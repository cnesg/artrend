Artnet·MutualArt·서울옥션·K옥션은 **영업/제휴팀에 직접 문의**해야 조건이 나온다(공개 페이지엔 없음). Artprice·

지켜온 "robots.txt/ToS 명시 허용만 수집" 원칙과 정면으로 배치된다.

### B-3. K-ARTMARKET 낙찰 결과 검색 페이지

이미 R5-통계에서 쓴 `MarketSizeProgress.do`(연도별 집계표)와 별개로, 사이트 내 로트 단위 검색을 찾아봤으나
`/member/auction/AuctionOrgList.do`(회원 경매사 명단), `/member/auction/Ing_AuctionList.do`(진행중 경매 목록,
로트 단위 낙찰가 없음) 뿐 — **로트 단위 공개 검색 페이지는 없음**. 연간 집계 이상은 이 소스로 못 얻는다(기존
결론 그대로).

### B-4. 예술경영지원센터(KAMS) 경매 결과 원자료

`gokams.or.kr`은 robots.txt가 관리자/검색 경로만 차단(`/09_search/total_search.aspx` 등)해 일반 페이지는
열람 가능. 다만 이번 재조사에서는 "미술시장 실태조사" 발간자료(PDF) 존재 여부까지만 확인했고 로트 단위 원자료
게시 여부는 미확인 — K-ARTMARKET이 같은 실태조사 수치를 이미 서버렌더 표로 제공 중이라 우선순위 낮음(09-15
문서 결론 유지).

### B-5. Wikidata P793(auction) 최신 증분

기존 `crawlers/auctions.py`가 쓰는 조건(`P793=Q177923`, PQ585 낙찰일)으로 SPARQL 직접 조회 결과:
**2024년 이후 낙찰일 아이템 154건**(전세계, 전체 art_type 통합) — 지난 R4 수집(2026-09-15) 이후 신규 statement가
소량 계속 쌓이고 있다는 뜻. 이미 있는 크롤러를 그대로 재실행하는 것만으로 소규모 증분 확보 가능(신규 소스
아님, 기존 크롤러 재실행 큐로 제안).

### B-6. Kaggle/GitHub 공개 데이터셋

- Kaggle "Art Price Dataset"류는 대체로 Artprice.com 등에서 개인이 스크레이핑해 올린 것으로 라이선스·재수집
  허가가 불투명(원 사이트 ToS를 우회한 데이터일 가능성) — 프로젝트 원칙(출처가 명확한 합법 소스)과 안 맞음.

  둘 다 부족(수십~수백 건, 갱신 안 됨) — 파이프라인 소스로 부적합.
- 결론: 이 축은 유의미한 대안 아님.

## C. 권고안

### 지금 바로 무료로 가능 (메인 승인 시 워커 착수 가능)
1. **Wikidata P793 크롤러 재실행**(`crawlers/auctions.py --type all`) — 신규 소스 아님, 기존 크롤러 재실행만으로
   154건 내외 증분. 비용 0, 즉시 가능.
2. **국내 경매사 4곳(서울옥션·K옥션·라이즈아트·칸옥션) robots.txt는 통과** — 단 ToS 원문 확인 전까지는 크롤러
   작성 보류 권고. ToS 확인이 끝나면 Bonhams와 동일한 패턴(세일 페이지 SSR/JSON 파싱)으로 즉시 착수 가능한
   후보.
3. **Sotheby's·Phillips도 robots.txt만으론 재검토 여지 있음** — 마찬가지로 ToS 원문 확인이 선행 조건.

### 사용자 예산 결정 필요 (유료)
1. **Artnet·MutualArt·서울옥션·K옥션에 데이터 제휴 문의** — 공개 페이지에 조건이 없어 영업팀 문의가 사실상
   유일한 경로. 문의 자체는 비용이 안 들지만, 회신 받은 라이선스 조건 검토는 사용자 판단 필요.
2. **Artprice/Invaluable/LiveAuctioneers는 공식 API 자체가 없음** — 서드파티 스크레이퍼(Apify 등) 경로는
   대상 사이트 ToS 위반 소지가 커서 프로젝트 원칙상 권장 안 함(유료를 써도 이 경로는 회피 권고).

### 판단 보류(다음 단계로 넘기지 않음, 기록만)
