# Swann Auction Galleries(뉴욕, swanngalleries.com) 조사 — 2026-09-22

## 최종 판정: **불가 — 능동적 봇 차단(WAF)으로 확정**

robots.txt·이용약관 자체는 문제 없었으나, 사이트가 **User-Agent 문자열 기반 WAF로 브라우저가
아닌 모든 요청을 403 Access Denied로 차단**한다. 이걸 우회하려면 실제 브라우저인 척 UA를
위장해야 하는데, 이는 이 프로젝트가 기존에 Dorotheum·easyliveauction·Chiswick Auctions·
Roseberys에 적용한 것과 동일한 "능동적 봇 차단 = 우회하지 않고 제외" 원칙에 해당한다.

## 1. robots.txt

- 지시받은 UA(`Mozilla/5.0 (artgraph-research-bot)`)로 요청 시 **403 Access Denied**
  (커스텀 WAF 페이지 — Client IP/Request ID/Timestamp를 보여주는 전형적 보안정책 차단 화면).
- 실제 Chrome UA(`Mozilla/5.0 ... Chrome/120.0.0.0 Safari/537.36`)로는 **200**, 내용은:
  ```
  User-agent: *
  Disallow:
  Sitemap: https://www.swanngalleries.com/sitemap_index.xml
  ```
  즉 robots.txt 자체는 완전 허용이다 — **문제는 robots.txt 내용이 아니라 그 앞단의 WAF**.

## 2. WAF 차단 범위 확인 (UA 문자열 여러 개로 교차 검증)

| User-Agent | robots.txt | /auctions/past | /sitemap_index.xml |
|---|---|---|---|
| `Mozilla/5.0 (artgraph-research-bot)` | 403 | 403 | 403 |
| `Mozilla/5.0` (단독) | 403 | - | - |
| `Mozilla/5.0 (compatible; artgraph-research-bot)` | 403 | - | - |
| UA에 `crawler` 포함 | 403 | - | - |
| `python-requests/2.31.0` | 403 | - | - |
| UA 없음(curl 기본) | 403 | - | - |
| `ClaudeBot/1.0` | 403 | - | - |
| 실제 Chrome 풀 UA 문자열 | **200** | 404(경로 자체가 다른 듯) | - |

→ **브라우저를 정확히 흉내 낸 완전한 UA 문자열이 아니면 사이트 전역에서 403**이다. robots.txt만
막힌 게 아니라 sitemap·일반 경로까지 동일하게 차단된다 — Cloudflare 챌린지형 사이트들(Dorotheum
등)과 메커니즘은 다르지만(여긴 UA 패턴 매칭형 WAF, 그쪽은 JS/PoW 챌린지) **"봇으로 식별되면
거부한다"는 사이트의 의사 자체는 동일**하다.

정직하게 봇임을 밝히는 UA(`artgraph-research-bot`, `ClaudeBot` 포함)가 전부 거부되고, 오직
실제 브라우저인 척 위장했을 때만 통과된다는 사실 자체가 "자동 수집을 원치 않는다"는 명확한
신호로 판단했다. 이 프로젝트 원칙(`우회는 봇 탐지 우회라 하지 않는다`)에 따라 **UA 위장으로
뚫지 않고 여기서 중단**한다.

## 3. 이용약관 확인 (참고용 — 위 판정과 무관하게 어차피 진행 안 하지만 기록)

- 푸터의 "Terms and Conditions" 링크(`/terms-conditions/`)는 실제로는 **"Conditions of Sale"
  PDF로 302 리다이렉트**된다(`image.invaluable.com/.../Conditions-2025.pdf`, Swann이
  Invaluable 플랫폼을 부분적으로 쓰는 것으로 보임 — the-saleroom.com/Bonhams류와 유사 구조).
  내용은 응찰·낙찰·매매 조건(buyer's premium 27%/22%/12%, 배송, 하자담보 등)뿐이고
  **크롤링·스크래핑·데이터마이닝·harvesting·자동수집·personal-non-commercial-only 금지
  조항 없음** — 전문 확인(3페이지 전부 읽음).
- `/privacy-policy/`도 GDPR 관련 개인정보 처리 방침뿐이고 사이트 콘텐츠 수집·재사용에 대한
  제한 조항 없음(최종 수정 2019-09).
- 별도의 일반 "웹사이트 이용약관"(Website Terms of Use) 페이지는 찾지 못했다 — 있다면
  WAF에 막혀 있을 가능성도 있지만, 브라우저로 직접 탐색해도 못 찾았다.
- 즉 **ToS만 놓고 보면 Grisebach/Sworders와 동급으로 통과할 사이트**였다. 이번 배제 사유는
  전적으로 WAF다.

## 4. 낙찰결과 페이지 구조 (참고용 — 미착수)

- 실제 Chrome UA로 접근한 `/auctions/past`는 404를 반환 — 정확한 URL 경로를 못 찾았다(WAF
  때문에 curl로 경로 탐색을 반복할 수도 없어 추가 확인 안 함). Conditions of Sale 12항에
  "A list of prices realized is published on our website www.swanngalleries.com at the
  conclusion of the sale"라고 명시돼 있어 페이지 자체는 존재하는 것으로 보이나, 구조(SSR
  여부)는 **미확인**.
