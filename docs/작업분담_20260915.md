## 0. 공통 규칙 (자율운영기준 §2 위에 추가)

1. **모든 DB 변경은 리포트 → 검수 → `--apply`** 두 단계. 리포트 없이 바로 바꾸는 스크립트 금지.
2. 스크립트는 idempotent(재실행 시 0건)여야 하고, `pipeline/maintenance_YYYYMMDD_*.py`가 아니라 기존 관례대로 `pipeline/<동사>_<대상>.py`로 짓되 **파일 상단 docstring에 "2026-09-15 작업분담 §N" 표기**.
3. DB URL 하드코딩 금지 — `from db import get_connection` 사용(`pipeline/.env` 로드).
4. 완료·중단·발견 즉시 이 문서의 자기 절에 한 줄 기록 + artrend-ca에 SendMessage.
5. 두 세션이 같은 테이블에 동시에 대량 쓰기 하지 않도록 아래 "테이블 소유" 준수. 소유 밖 테이블을 건드려야 하면 먼저 물을 것.
6. 새 소스·새 크롤러 추가 금지. LLM으로 결손 채우기 금지.
