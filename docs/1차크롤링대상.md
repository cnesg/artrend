# 1차 크롤링 대상 확정

로드맵 1단계 산출물. 우선순위: **① 국내·미국 공공 미술관 → ② 사유 갤러리 → ③ 유명 컬렉터**, 각 소장품의 작가정보·제작년도·작품기본정보·경매가·추정가·비평요약까지 잇는 지식베이스 구축이 목표.

## ① 공공 미술관 (최우선)

### 국내

| 기관 | 데이터 소스 | 수집 방식 | 커버리지 | 판정 |
|---|---|---|---|---|
| 국립중앙박물관 (e뮤지엄) | [공공데이터포털 - e뮤지엄 유물정보 OpenAPI](https://www.data.go.kr/data/15104964/openapi.do) | 공공데이터 API (키 발급) | 유물명·국적/시대·재질·크기·주제분류 등 | ❌ **제외** (2026-09-02) — 이름 그대로 유물(문화재) 전반 데이터라 프로젝트 스코프(미술품)와 어긋남. 발급 신청 자체를 하지 않기로 함 |
| 전국 20개 기관 통합 유물정보 | [문화체육관광부 20개 기관 유물정보 OpenAPI](https://www.data.go.kr/data/15105038/openapi.do) | 공공데이터 API | 국립박물관+문화재청+지자체 소장품 통합 | ❌ **제외** (2026-09-02) — 위와 동일 사유 |
| 국립현대미술관 (MMCA) | 공식 오픈API 없음. 소장품 검색 페이지가 쓰는 내부 JSON 엔드포인트(`/collections/AjaxCollectionsList.do`) 이용 | 내부 API 호출 (웹 크롤링 아님) | 근현대 미술 전문 — 우리 서비스와 가장 밀접 | ✅ **완료** — robots.txt 재확인(2026-09-02) 결과 이 엔드포인트는 허용 범위. **11,749건 전체 수집 완료.** 이미지 저작권은 레코드별 `copyrightAllowYn` 필드로 개별 확인 필요 |

### 미국

| 기관 | 데이터 소스 | 수집 방식 | 커버리지 | 판정 |
|---|---|---|---|---|
| The Met (Metropolitan Museum of Art) | [Open Access API](https://metmuseum.github.io/) | REST API, JSON | 47만+ 작품, CC0 (이미지 포함) | ✅ **가능** — 최우선 착수 대상 |
| Smithsonian Institution | [Open Access API](https://github.com/Smithsonian/OpenAccess) | REST API | 1,100만+ 메타데이터 | ✅ **가능** |
| Art Institute of Chicago | [Open Access API](https://www.artic.edu/open-access) | REST API | 이미지+데이터+소스코드 공개 | ✅ **가능** |
| Cleveland Museum of Art | [Open Access API](https://openaccess-api.clevelandart.org/) | REST API | 6.4만+ 작품, 3.7만+ 이미지 | ✅ **가능** |
| National Gallery of Art (Washington) | [opendata (GitHub)](https://github.com/NationalGalleryOfArt/opendata) | CSV 덤프, 매일 갱신 | 13만+ 작품 + **작가·기증자·프로버넌스 관계 데이터 포함** | ✅ **가능** — provenance_records 채우기에 가장 적합 |

> NGA는 소장품뿐 아니라 **기증자(donor)·프로버넌스** 관계까지 구조화 데이터로 제공 — `provenance_records` / `museum_holdings` 초기 적재 최적 소스로 최우선 배정.

## ② 사유 갤러리

공공 API가 존재하는 곳이 없음. 갤러리 자체 웹사이트(작가 로스터, 전시 이력 페이지)를 대상 사이트별로 robots.txt/ToS 확인 후 개별 크롤링해야 함.

| 판정 | 내용 |
|---|---|
| ❌ **Gagosian 제외** (2026-09-02) | robots.txt에 `Content-Signal: ai-train=no` + `ClaudeBot`/`GPTBot`/`CCBot`/`Bytespider` 등 AI 봇을 이름으로 명시 차단. 명확한 거부 시그널이라 제외 확정. |
| ❌ **Hauser & Wirth 제외** (2026-09-02) | robots.txt 요청 자체가 Vercel 봇 차단(Security Checkpoint)에 막혀 429 응답. 우회는 ToS 위반 소지가 커서 제외 확정. |
| ⚠️ **보류 — 사이트별 개별 검토** | Pace, David Zwirner, White Cube 등은 아직 미조사. 국내는 국제갤러리·PKM·갤러리현대 등이 후보. |
| 대안 | 갤러리 자체 크롤링보다 **Artsy**(무료 열람 가능, 갤러리·작가 정보 집계)를 경유해 갤러리 대표 작가 관계를 먼저 채우는 방법도 검토 |

## ③ 유명 컬렉터

컬렉터 전용 공개 데이터베이스는 사실상 없음. 컬렉터 정보는 **1차 소스가 아니라 파생 소스**로 다뤄야 함:

- NGA 오픈데이터의 기증자(donor) 필드
- 미술관 소장품의 "acquisition_method = 기증/유증" 레코드에 붙는 기증자명
- 경매 카탈로그의 프로버넌스 문구(예: "Property from the Collection of ...")

→ `collectors` 테이블은 별도 크롤러를 만들지 않고, 위 소스들을 파싱하면서 **레코드 발견 시점에 upsert**하는 방식으로 채운다. (로드맵 3단계 크롤러 설계에 반영)

## 지식베이스 확장 — 가격·추정가·비평요약

| 항목 | 소스 후보 | 판정 |
|---|---|---|
| 경매 낙찰가 | Artsy(무료 열람), 국내 서울옥션·K-Auction 공개 결과 페이지 | ⚠️ 사이트별 ToS 확인 후 개별 진행. Artnet·Artprice는 04·수집원칙에 따라 **제외 확정** |
| 현재 추정가 | 경매사 공개 프리뷰(추정가 estimate) 페이지 | ⚠️ 경매 페이지 크롤링과 동일 범주로 처리 |
| 비평요약 | Artforum·ARTnews·Frieze 등 전문지 | 🚫 **전문 스크래핑 금지** — 대부분 저작권 보호 텍스트. 공식 보도자료·미술관 wall text(재사용 허용 명시된 것)만 수집하고, 제3자 비평은 링크+짧은 인용(fair use) 수준으로만 저장 |

## 결론 — 착수 순서

1. **The Met + National Gallery of Art (미국)** 오픈 API/데이터로 크롤러 1차 구현 (가장 구조화되어 있고 provenance까지 포함)
2. **e뮤지엄 + 20개 기관 통합 API (국내)** 병행 — 공공데이터포털 API 키 발급 선행
3. Smithsonian / Art Institute of Chicago / Cleveland 순차 추가
4. MMCA·사유 갤러리는 robots.txt/ToS 개별 검토 후 2차로 확대
5. 컬렉터·비평요약은 전용 크롤러 없이 위 소스들의 부산물로 채움
