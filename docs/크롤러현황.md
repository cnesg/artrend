# 크롤러 현황 — 자동 진행분 vs 사용자 개입 필요분

착수리포트 로드맵 3단계(크롤러 개발) 진행 상황. 인증키/계정 발급이나 법적 판단이 필요 없는 부분은 바로 구현·테스트까지 마쳤고, 그 외는 아래 "사용자 개입 필요" 목록에 정리했다.

## ✅ 완료 — 키 없이 바로 동작 확인

| 크롤러 | 파일 | 상태 | 비고 |
|---|---|---|---|
| The Met | `crawlers/met.py` | 테스트 완료 (3건 수집 확인) | 부서별 오브젝트 목록 → 개별 조회 |
| Art Institute of Chicago | `crawlers/aic.py` | 테스트 완료 (5건 수집 확인) | provenance_text·exhibition_history 필드까지 포함 |
| Cleveland Museum of Art | `crawlers/cleveland.py` | 테스트 완료 (5건 수집 확인) | skip/limit 페이지네이션 |
| National Gallery of Art | `crawlers/nga.py` | **핵심 4개 CSV 다운로드 완료** (126MB) | `objects.csv`에 `provenancetext` 직접 포함 — provenance_records 채우기에 최적. `published_images.csv`(89MB, 이미지 메타)는 필요 시 `--files`로 추가 다운로드 가능하게 옵션만 열어둠 |

수집된 원본은 `crawlers/raw/<site>/`에 `.json`/`.csv` + `.meta.json`(출처 URL·수집시각·라이선스) 쌍으로 저장됨.

## ✅ 완료 — 읽기 전용 조사 (robots.txt)

갤러리/MMCA는 크롤링 여부를 최종 결정하기 전에 robots.txt만 먼저 확인했다 (판단은 아래 "개입 필요" 항목).

| 사이트 | robots.txt | 특이사항 |
|---|---|---|
| MMCA (국립현대미술관) | HTTP 400 — robots.txt 없음 | 크롤링 정책이 명시돼 있지 않음 → 기관 문의 필요 |
| Gagosian | 허용, 일부 경로 제외 | **`Content-Signal: ai-train=no` 명시** — AI 학습 목적 사용을 명시적으로 금지. 우리 파이프라인은 LLM 위키에 데이터를 쓰므로 이 사이트는 사실상 제외 권장 |
| Pace Gallery | 허용, `/p/`·PDF·비공개쇼 등 제외 | 특이사항 없음 |
| David Zwirner | 전체 허용 (`/api/*` 제외) | 특이사항 없음 |
| Hauser & Wirth | HTTP 429 (요청 제한) | 재확인 필요, 크롤링 시 매우 낮은 속도로 접근해야 할 가능성 |
| White Cube | 허용, 일부 시스템 경로 제외 | 특이사항 없음 |
| Artsy | 허용, 검색/일부 쿼리 제외 | 갤러리·작가·경매 sitemap 별도 제공 — 통합 수집 소스로도 적합 |
| 국제갤러리 | 전체 허용 | 특이사항 없음 |
| PKM갤러리 | 전체 허용 | 특이사항 없음 |
| 갤러리현대 | 허용, 검색/다운로드 제외 | 특이사항 없음 |

## ⏸️ 준비만 완료 — 사용자 개입 필요

| 항목 | 왜 개입이 필요한가 | 준비된 것 |
|---|---|---|
| **e뮤지엄 (국립중앙박물관) API 키** | data.go.kr은 계정 로그인 후 "활용신청"을 해야 정확한 엔드포인트·파라미터 스펙이 공개됨 — 본인 계정 필요 | `crawlers/emuseum.py` 스켈레톤 작성 완료. `data.go.kr` → [e뮤지엄 유물정보](https://www.data.go.kr/data/15104964/openapi.do) 활용신청 → 발급된 서비스키를 `EMUSEUM_API_KEY`로 전달하면 나머지 로직(TODO 2곳: 정확한 엔드포인트, 응답 items 경로)만 스펙 보고 채우면 바로 동작 |
| **Smithsonian API 키** | api.data.gov 키 발급 필요 (이메일 가입, 즉시 발급이지만 계정 소유권 문제로 직접 안 함) | 아직 크롤러 미작성 — 키 발급되면 met.py 패턴 그대로 재사용해 빠르게 작성 가능 |
| **MMCA 크롤링 여부 결정** | robots.txt가 없어 정책 불명 — 크롤링 강행 여부는 법적 판단 필요, 또는 기관에 직접 데이터 제공 문의가 안전 | 조사만 완료, 실행 안 함 |
| **Gagosian 제외 여부 확정** | `ai-train=no` 시그널을 존중할지 정책적 판단 필요 | 조사 완료, 기본적으로 제외 권장이지만 최종 결정은 사용자 몫 |
| **Hauser & Wirth 재시도 여부** | 429 응답 — 크롤링 강행 시 속도조절 정책 필요, 이용약관도 별도 확인 필요 | 조사만 완료 |
| **갤러리 이용약관(ToS) 본문 검토** | robots.txt는 기술적 허용일 뿐, 실제 법적 이용약관은 별도 — 저작권/상업적 이용 조항은 법적 판단이 필요해 자동 진행하지 않음 | robots.txt 결과까지만 정리 |
