## ❌ 제외 확정

| 대상 | 사유 |
|---|---|
| e뮤지엄 / 공공데이터포털 "20개 기관 통합 유물정보" API | 유물(문화재) 전반 데이터라 프로젝트 스코프(미술품)와 어긋남 — 신청 자체를 하지 않기로 함 |
| Gagosian | robots.txt에 `Content-Signal: ai-train=no` + `ClaudeBot`/`GPTBot`/`CCBot` 등 AI 봇 명시 차단 |
| Hauser & Wirth | robots.txt 요청 자체가 Vercel 봇 방화벽(429)에 막힘 |
| 원앤제이갤러리 | 사이트 자체가 HTTP 410(Gone) — 서비스 종료/개편 추정 |

## ⏸️ 확인됨 — 사용자 판단/키 발급 필요

| 대상 | 상태 |
|---|---|
| Rijksmuseum (네덜란드) | 데이터는 우수하나 옛 공개 데모키(`0fiuZFh4`)가 410로 폐기됨 — 정식 API 키는 본인 이메일로 신청 필요 (data.rijksmuseum.nl) |
| Europeana (유럽 통합 아카이브) | 옛 공개 데모키(`api2demo`)가 아직 살아있으나 **테스트용 저용량 키**라 대량 수집엔 부적절 — 정식 키는 본인 이메일로 신청 필요, 4.75억+ 건 규모라 신청 가치 있음 |
| 일본 독립행정법인 국립미술관 통합검색 (도쿄/교토 국립근대미술관, 국립서양미술관 등) | `search.artmuseums.go.jp` — robots.txt가 아예 없는(404) 정부기관 사이트라 MMCA 초기와 같은 애매한 상황. 폼 기반 구식 검색이라 기술적으론 긁을 수 있지만, 정책 판단 없이 진행하지 않고 후보로만 남겨둠 |
| 리만머핀·페로탕 (갤러리) | robots.txt는 허용이나 클라이언트 렌더링(SPA)이라 requests만으로 작가 목록을 못 긁음 — 헤드리스 브라우저 필요 |
| 리안갤러리·학고재 (갤러리) | SSL 인증서 오류로 접속 자체가 안 됨 — 재확인 필요 |

## ⏸️ 미조사 — 다음 후보

경매: Artsy(무료 열람 가능, 갤러리·작가·경매 sitemap 별도 제공), 서울옥션·K-Auction 공개 결과 페이지 — `1차크롤링대상.md` "지식베이스 확장" 절 참고. Artnet·Artprice는 유료·ToS 크롤링 금지로 제외 확정.

## 파이프라인 적재 상태

`pipeline/`에 met/aic/cleveland/nga/smithsonian/mmca/smk/moma/tate/galleries 로더 전부 작성 완료, dry-run 파싱 검증 통과. 실제 Supabase 적재는 met(6)/aic(5)/cleveland(5)/nga(145,658)만 끝났고 나머지는 로더만 준비된 상태 — 크롤링이 마저 끝난 뒤 한 번에 돌릴 예정. 자세한 내용은 `CLAUDE.md`의 "파이프라인 상태" 절 참고.
