## ✅ 전체 수집 완료

| 크롤러 | 파일 | 건수 | 비고 |

## ❌ 제외 확정

| 대상 | 사유 |
|---|---|
| e뮤지엄 / 공공데이터포털 "20개 기관 통합 유물정보" API | 유물(문화재) 전반 데이터라 프로젝트 스코프(미술품)와 어긋남 — 신청 자체를 하지 않기로 함 |
| Gagosian | robots.txt에 `Content-Signal: ai-train=no` + `ClaudeBot`/`GPTBot`/`CCBot` 등 AI 봇 명시 차단 |
| Hauser & Wirth | robots.txt 요청 자체가 Vercel 봇 방화벽(429)에 막힘 |
| 원앤제이갤러리 | 사이트 자체가 HTTP 410(Gone) — 서비스 종료/개편 추정 |

## ⏸️ 미조사 — 다음 후보 (사용자 승인 시 자동 진행 가능)

국내: 리안갤러리(SSL 인증서 오류로 확인 실패, 재시도 필요), 학고재(SSL 오류)
해외(서울 지점 있는 대형 갤러리): 리만머핀, 페로탕, 페이스갤러리 — robots.txt는 확인됨(허용), 사이트별 작가 목록 HTML 구조 파악만 남음
경매: Artsy(무료 열람 가능, 갤러리·작가·경매 sitemap 별도 제공), 서울옥션·K-Auction 공개 결과 페이지 — `1차크롤링대상.md` "지식베이스 확장" 절 참고. Artnet·Artprice는 유료·ToS 크롤링 금지로 제외 확정

## 파이프라인 적재 상태

`pipeline/`에 met/aic/cleveland/nga/smithsonian/mmca 로더 전부 작성 완료. 실제 Supabase 적재는 met(6)/aic(5)/cleveland(5)/nga(145,658)만 끝났고, smithsonian/mmca/galleries는 로더만 있고 아직 실행 전 — 크롤링이 마저 끝난 뒤 한 번에 돌릴 예정. 자세한 내용은 `CLAUDE.md`의 "파이프라인 상태" 절 참고.
