## ⏸️ 미조사 — 다음 후보

경매/가격 데이터 소스는 조사한 3곳(Artsy, 서울옥션, K-Auction) 전부 명확한 법적 제약(ToS 크롤링 금지 조항 또는 저작권법 근거 고지)으로 제외 확정됨(2026-09-02) — Artnet·Artprice(유료)까지 포함하면 주요 경매/가격 데이터 소스는 사실상 전부 막힌 상태. 남은 대안은 개별 경매 결과를 다루는 언론 보도(이미 `crawlers/`에 없음, 신규 조사 필요)나 미술관 소장품의 `credit line`/`provenance` 텍스트에서 간접적으로 드러나는 구입가 정보 정도 — 별도 방법론 필요, 사용자 판단 대기.

## 파이프라인 적재 상태

`pipeline/`에 met/aic/cleveland/nga/smithsonian/mmca/smk/moma/tate/galleries 로더 전부 작성 완료, dry-run 파싱 검증 통과. 실제 Supabase 적재는 nga(145,658) 완료, smithsonian/mmca/moma/tate/galleries 진행 중, met(270,462건 대상)·aic·cleveland는 순차 적재 예정 — 자세한 내용은 `CLAUDE.md`의 "파이프라인 상태" 절 참고. `crawlers/europeana.py`·`crawlers/japan_museums.py`는 크롤러만 작성됨, `pipeline/` 로더는 아직 없음(다음 작업).
